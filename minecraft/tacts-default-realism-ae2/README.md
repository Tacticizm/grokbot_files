# Tact's Default Realism: AE2

An add-on resource pack for **Applied Energistics 2**, made to sit on top of **Tact's Default Realism** (128x).
It redraws AE2's block, part (cables, buses, terminals, monitors), item, entity and particle textures at 128x
(8x vanilla) in the main pack's style: crisp pixel grid, top-left light, shiny light-steel and gunmetal casings,
pale certus, purple fluix and dark sky stone, while keeping AE2's original colours, shapes and UV layouts.
Animated textures keep AE2's frame timings, and colour-tinted layers stay greyscale so in-game tinting works.

536 textures.

## Requirements

- Minecraft 26.1.2 with NeoForge 26.1.2
- Applied Energistics 2 **26.1.13-beta**
- **Tact's Default Realism** (the main pack), loaded *below* this add-on

## Install

1. Put `Tacts-Default-Realism-AE2.zip` in your `.minecraft/resourcepacks` folder (do not unzip it).
2. In Options > Resource Packs, enable both **Tact's Default Realism** and **Tact's Default Realism: AE2**.
3. Order them with **Tact's Default Realism: AE2 above Tact's Default Realism** in the selected list.
4. Click Done and let the resources reload.

## Notes

- GUI and guide textures stay vanilla: AE2's `gui`, `guis`, `ae2guide` and Patchouli textures are not changed
  (their fixed UV layouts don't allow a redraw at a different size), so screens and the guide look like stock AE2.
- A handful of debug and creative-only textures are left as AE2 ships them.
- Different AE2 versions may add or rename textures; anything not covered falls back to AE2's own texture.
