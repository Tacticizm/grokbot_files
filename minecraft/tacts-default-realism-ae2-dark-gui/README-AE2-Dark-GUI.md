# Tact's Default Realism: AE2 Dark GUI

An add-on resource pack that gives **Applied Energistics 2**'s screens a dark theme: near-black panels with a fluix
purple rim and cyan accents, recessed dark slots with crisp bevels, dark buttons and scrollbars, and light text that
stays readable. Every texture keeps AE2's original size and layout (it is a restyle, not an upscale), so slots,
buttons and widgets sit exactly where AE2 puts them.

48 GUI textures and 3 screen style files (text colours).

## Requirements

- Minecraft Java 26.1.2 to 26.3 with NeoForge
- Applied Energistics 2 **26.1.13-beta**
- Works on its own, or together with **Tact's Default Realism** and **Tact's Default Realism: AE2** (the packs share no files)

## Install

1. Put `Tacts-Default-Realism-AE2-Dark-GUI.zip` in your `.minecraft/resourcepacks` folder (do not unzip it).
2. In Options > Resource Packs, enable **Tact's Default Realism: AE2 Dark GUI** (and the main pack / AE2 add-on if you use them).
3. Any order works, since no files overlap.
4. Click Done. If textures look scrambled after changing packs, restart the game; a live reload can mis-stitch the texture atlas.

## Notes

- The JEI recipe overlay (`jei.png`) is left as AE2 ships it, so it matches JEI's own light recipe window.
- Text colours come from AE2's screen style files and are set to light colours here; any text colour AE2 sets in its code can't be changed by a resource pack.
- Other mods' panels (JEI/EMI side bars, tooltips from other mods) keep their own look.
- Different AE2 versions may add or rename GUI textures; anything not covered falls back to AE2's own texture.
