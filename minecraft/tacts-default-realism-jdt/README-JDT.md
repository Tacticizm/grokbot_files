# Tact's Default Realism: Just Dire Things

An add-on resource pack for **Just Dire Things**, made to sit alongside **Tact's Default Realism** (128x).
It redraws Just Dire Things' blocks (material and coal blocks, raw ores, time crystals, goo blocks and goo soil,
machines and their tier-2 versions, paradox machine, fluids), items (ferricore, blazegold, celestigem and eclipse
alloy tools, bows and armour, wands, canisters, gadgets, ability upgrades), worn armour, projectiles and particles at
128x (8x vanilla) in the main pack's style: crisp pixel grid, top-left light, shiny light-steel, gunmetal and copper
metals, gem cells and oak wood, while keeping the mod's original colours, shapes and UV layouts. Animations keep their
timing, and colour-tinted parts (fluids, canister fill levels, the paradox vortex) stay greyscale so in-game tinting works.

319 textures.

## Requirements

- Minecraft Java 26.1.2 to 26.3 with NeoForge
- Just Dire Things **1.6.11**
- **Tact's Default Realism** (the main pack), enabled alongside this add-on

## Install

1. Put `Tacts-Default-Realism-JDT.zip` in your `.minecraft/resourcepacks` folder (do not unzip it).
2. In Options > Resource Packs, enable both **Tact's Default Realism** and **Tact's Default Realism: Just Dire Things**.
3. Either order works (the packs share no files); the tested setup is this add-on below the main pack.
4. Click Done. If textures look scrambled after changing packs (blocks showing the wrong texture), restart the game; at 128x a live reload can mis-stitch the texture atlas.

## Notes

- GUI and guide-book textures stay as Just Dire Things ships them (their fixed UV layouts don't allow a redraw at a different size).
- 24 textures that the mod ships but never uses (old goo render frames, unused pocket generator tiers, fuel canister fill
  stages, the polymorph upgrade icons, and two leftover block faces) are not included.
- Different Just Dire Things versions may add or rename textures; anything not covered falls back to the mod's own texture.
